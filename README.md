# SOC-Investigations-Simulations

A collection of hands-on Security Operations Center (SOC) investigations completed through simulated security environments and labs.

The repository documents the investigation process, evidence, alert classification, indicators of compromise (IOCs), escalation decisions, and recommended response actions.

## Investigations

| Platform  | Investigation                                                     | Focus                                 |

## Evidence

Each investigation contains relevant screenshots and a detailed case report based on the evidence observed during the investigation.

> **Note:** These investigations are performed in simulated environments for learning and portfolio purposes.
